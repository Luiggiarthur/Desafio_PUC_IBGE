Desafio de Ciências de dados proposto pela PUC Minas, utilizando dados do IBGE:<br>
<br>
Neste desafio foi proposto a utilização da base de dados do IBGE para gerar insights e informações sobre o Brasil.
Os resultados obtidos em minha análise demonstra a estratificação do País em relação à cor e região.<br> 
Através de técnicas de clustering foi observado como os Estados possuem características próximas à região em que pertencem,
no entanto, a Bahia se aproximou mais do sudeste de acordo com o modelo utilizado, isso se deve as características analisadas pelo modelo.
